A one-page visual summary of the world's news on Wednesday 18 November 2026 — US–Iran strikes, the Kerch Bridge collapse, APEC in Shenzhen, the US measles ruling, Congo's Ebola outbreak, the completed US Senate map, Cyclone Xavier and the day's markets — drawn as a single 1024×1024 infographic. The HTML source (news.html) is rendered once to entry.png by render.mjs; main.ts copies that image to the output directory, byte for byte, every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
